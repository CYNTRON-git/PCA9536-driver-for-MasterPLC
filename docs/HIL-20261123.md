# Испытание системного драйвера на СА‑02м, 23 ноября 2026 года

Испытание выполнено на физической СА‑02м со штатным ПО `1.0.7.39`. Системный драйвер собран из коммита `e344120742aad5bfb9e657844d4434c905df2ca6` с SDK `1.3.10.35699`. SHA‑256 установленного `mplc_cyntron.so` — `e01e7c69d215a9fc0fd3733034ba6a28424dd18fd419a04f323e3757be54380a`. Процесс MasterPLC отобразил в память проверенный файл.

| Проверка | Наблюдение на плате |
|---|---|
| 17 диагностических каналов | Стендовая программа получила значения для всех 17 имён. Проверялись функции поставленного драйвера, функции runtime и пути чтения из исходников. Модем и USB-накопитель отсутствовали, SD-карта была смонтирована. |
| Источник RTC | Внутренний SoC RTC показывал 1970 год. Внешний DS3231 на I²C1, адрес 0x68, показывал 2026 год. После исправления канал прочитал UTC с внешнего RTC и совпал с системными часами до секунды. Календарь прочитан одним блоком, статус отдельной транзакцией. |
| Красный и синий светодиоды, зуммер, DOUT | Каждый выход по отдельности переведён из исходного состояния и возвращён. Изменение и восстановление подтверждены в регистрах вывода и входа PCA9536. |
| Совместный доступ к PCA9536 | Пока штатная функция панели удерживала файловую блокировку от имени `www-data`, драйвер сообщил о занятой шине. После освобождения блокировки чтение прошло. |
| Питание USB | При временной передаче управления драйверу ядро зарегистрировало уровни `1 → 0 → 1`. Первоначальная служба и высокий уровень восстановлены. При активной штатной службе даже команда включения уже включённого выхода вернула `EBUSY`, владелец и уровень сохранились. Одновременное управление от панели и MasterPLC требует согласования владения GPIO 268. |
| Лицензия | Штатный файл состояния создан с правами `0644`. На этом контроллере `activated=false`, `key_error=1`. |

Для проверки напряжения на клемме, звука и фактической нагрузки нужны независимые приборы или наблюдение на месте. Для сквозной проверки всех 22 переменных в VM требуется штатный экспорт проекта MasterSCADA 4D с экземплярами `CyntronProtocol` и `CA_02m`. Рабочий каталог проекта контроллера на момент проверки был пуст. Проект FastModbus на 554 канала использован для проверки загрузки плагинов и обмена по своему протоколу.

Журналы Mac mini находятся в `artifacts/linux/sa02m-136-hil-20261123T095010Z` общего рабочего каталога. Вывод аппаратных проб записан в `system-final-diagnostics.txt`, `system-final-control.txt`, `system-usb-busy.txt` и `pca-contention.txt`.
